# অ্যাডমিন > 🗑 বিন ও ডিলিট: প্রিভিউ + ফিল্টার + একসাথে রিস্টোর/ডিলিট (ভাগ ৩)

- বিন-বক্সের ওপরে ফিল্টার-সারি: ধরন · বিভাগ · সেশন · স্কোর-পরিসর · মোছার সময় (শেষ ১ ঘণ্টা/৬ ঘণ্টা/২৪ ঘণ্টা/৭ দিন/কাস্টম = datetime-local থেকে/পর্যন্ত) · নাম/ডিভাইস। বড় "🔎 সার্চ" বাটন (data-a="bfgo"; Enter-ও চলে)। বদলালেই অটো-সার্চ নয়। বিভাগ/সেশন/স্কোর ক্লায়েন্টেই row থেকে ফিল্টার।
- প্রতি সারিতে চেকবক্স; "☑ এই পেজের সব বাছো · ☑ ফিল্টারের সব বাছো · ✖ বাছা বাদ"; "বাছা N টি" + "↩ বাছাগুলো রিস্টোর" / "🗑 বাছাগুলো চিরতরে ডিলিট"।
