# ২০২৬-১২-০৯ — ধাপ ৩: এক্সেল ফাইলের কমন ডিজাইন (শুধু 📊 ফলাফল ট্যাবে) — নতুন SQL লাগে না

**SQL:** কোনো নতুন SQL নেই। কোনো টেবিল/কলাম/ডাটা বাড়েনি; স্টোরেজেও কিছু জমে না (ফাইল শুধু অ্যাডমিনের ব্রাউজারে তৈরি হয়ে নামে)। আগের ৩ লাইনের `sql-status.md` যেমন ছিল তেমন (শুধু ২০২৬-১২-০৬-এর কুইজ-ছবি SQL আগের মতোই PENDING)।

## কী হলো
1. অ্যাডমিন › 📊 ফলাফল-এ পুরোনো CSV বাটন আগের মতোই; পাশে নতুন **"⬇ এক্সেল (সাজানো)"** বাটন। ফিল্টার (বিভাগ, সেশন, তারিখ, নাম, সেরা/সব খেলা) অনুযায়ী সব ফল (৫০০টি করে এনে, সর্বোচ্চ ২০,০০০) নামে; বাটনে প্রগ্রেস দেখায়।
2. নতুন কমন ফাইল **`admin-xlsx.js`** (`window.MCXLSX`): নিজেই .xlsx লেখে — **কোনো CDN/বাইরের লাইব্রেরি নেই, তাই `_headers`/`netlify.toml`-এর CSP বদলাতে হয়নি।** `admin.html`-এ `admin-results.js`-এর আগে লোড হয়; সাধারণ ভিজিটরের পেজে (`index.html`) নেই, তাই ভিজিটরের পেজ ভারী হয়নি। পরের ধাপে বাকি ট্যাব এটাকেই ডাকবে (`MCXLSX.results` / `save` / `zip`)।
3. ফাইলের শীট (ওপর থেকে নিচে): গাঢ় সবুজ (#0B3D2E) ব্যানার + সোনালি (#D4AF37) বর্ডার (MC Explorer Challenge, মুরারিচাঁদ কলেজ, সাইটের ঠিকানা (লিংক), রিপোর্টের তারিখ-সময়, কে বের করেছে (অ্যাডমিনের ইমেইল), মোট রেকর্ড, ফিল্টার, ডাটার উৎস, তথ্য-কলাম; `images/logo-mc.png` থাকলে লোগো) → ৪টা সারসংক্ষেপ বক্স (মোট খেলোয়াড়, গড় স্কোর, সর্বোচ্চ স্কোর, মোট কার্ড) → 🏆 সেরা তিনজন (সোনা/রুপা/ব্রোঞ্জ সারি; ক্লিকে টেবিলের ওই সারিতে যায়) → টেবিল (নাম-বার, উৎস-লাইন, হেডার; কলাম: ক্রমিক | র‍্যাংক (প্রথম তিনে 🥇🥈🥉) | **স্কোর** | নাম | বিভাগ | সেশন | ক্লাস | তারিখ) → ফুটার।
4. টেবিল-সাজ: গাঢ় হেডার + সাদা বোল্ড + ফ্রিজ + অটো-ফিল্টার, জেব্রা সারি, পাতলা বর্ডার, wrap, ফন্ট Nirmala UI, গ্রিডলাইন বন্ধ, ট্যাব-রঙ সোনালি, A4 ল্যান্ডস্কেপ, হেডার প্রতি পাতায় (প্রিন্ট-টাইটেল)।
5. স্কোর-ঘর "বাটনের মতো": ক্লাস অনুযায়ী রঙ (`D.classMetal`-এর ৬ ক্লাস; ক্লাস-নিয়ম `app.js`-এর `tierOf`-এর হুবহু), মোটা বর্ডার, বোল্ড সংখ্যা। স্কোর **আসল সংখ্যা** (সর্ট/যোগ চলে); ক্রমিক/র‍্যাংক বাংলা অঙ্কের লেখা। র‍্যাংক = সাইটের `mc2_board`-এর র‍্যাংক (সমান স্কোরে একই র‍্যাংক, বদলায়নি)।
6. সব লেখা টেক্সট হিসেবে বসে — তাই `=`, `+`, `-`, `@` দিয়ে শুরু নামও এক্সেলে ফর্মুলা হয়ে চলে না (CSV-র `'` যোগ করার দরকার নেই)।
7. ফাইলের নাম: `MC-Explorer-Results-<বছর-মাস-দিন>.xlsx` (ইংরেজি নাম, ফোনে ডাউনলোডে ঝামেলা কম)।

## নোট
- ওপরের সারি ২–১৯ **গ্রুপ** করা (বাঁ-পাশে ⊖/① ② বাটন): হেডার ফ্রিজ থাকায় ওপরের অংশ বড় জায়গা নেয়; ছোট পর্দায় ① চাপলে ওপরের অংশ ভাঁজ হয়ে টেবিল পুরো দেখা যায়।
- `admin-ux.js` পুরোনো CSV বাটনের "CSV" শব্দ UI-তে "এক্সেল-ফাইল" দেখায় (এটা আগে থেকেই ছিল, ছুঁইনি); তাই নতুনটার লেখা "⬇ এক্সেল (সাজানো)"।
- বদলানো/নতুন ফাইল: `admin-xlsx.js` (নতুন), `admin-results.js` (বাটন + `xlsx()`), `admin.html` (script ট্যাগ), `sw.js` (ক্যাশ ১৪৫ → ১৪৬), `status.html` (DESC), `files.txt`, এই নোট। CSP/`_headers`/SQL অপরিবর্তিত।
- যাচাই (এই সেশনে): নোডে ফাইল বানিয়ে openpyxl-এ ফ্রিজ/ফিল্টার/মার্জ/লিংক/সংখ্যা-টাইপ মিলিয়েছি; LibreOffice-এ খুলে ছবি দেখেছি (ব্যানার, বক্স, সেরা তিনজন, রঙিন স্কোর, প্রিন্টে হেডার প্রতি পাতায়); Chromium-এ আসল `admin.html` চালিয়ে (Supabase নকল করে) বাটন চাপলে ১২০০ সারির ফাইল নামে, এরর নেই। **দেখা হয়নি:** আসল Supabase ডাটা, মালিকের ফোন/Excel অ্যাপ। নমুনা `MC-Explorer-নমুনা-ডিজাইন.xlsx` আপলোড হয়নি, তাই ডিজাইন প্রম্পটের বিবরণ ধরে বানানো; নমুনার সাথে মিলিয়ে ছোটখাটো রঙ/মাপ বদলাতে হতে পারে।
