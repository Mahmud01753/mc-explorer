# 🚦 ফেসবুক-অনুমতি গেট — নাম বাছার সময় একটাই পপআপ

নতুন SQL নেই। নতুন টেবিল/কলাম/ডাটা নেই (শুধু আগের mc2_fbok পড়া)।

## কী বদলাল
যাদের 📣 ফেসবুক-অনুমতি নেই (❌ না বা ❔ দেয়নি; ডিভাইস ছাড়া হাতে-লেখা নামও) তাদের বাছতে গেলে পপআপ আসে:
- **একজনকে** টিক/➕ যোগ করলে: "তবুও যোগ করবেন?" (হ্যাঁ/বাতিল) — না বললে টিক বসে না।
- **অনেকজন একসাথে** (৫ / ৭ / ১০ / প্রথম N / সব) বাছলে: একটাই সম্মিলিত পপআপ। ওপরে কতজনের অনুমতি নেই লেখা; নিচে শুধু তাদের তালিকা (শুরুতে কারও টিক নেই)। যাদের টিক দেবেন শুধু তারা যোগ হবে; অনুমতি-আছে যারা তারা এমনিতেই যোগ হয়। ☑ সবাইকে টিক / ☐ কাউকে না বাটন আছে; বাটনে কতজন যোগ হবে দেখায়। ✖ বাতিল বা বাইরে চাপলে কিছুই বদলায় না।
- অনুমতির ডাটা (mc2_fbok) না এলে (SQL চালানো না থাকলে) পপআপ আসে না, আগের মতোই চলে।

## ফাইল
- admin-fbc.js — নতুন `MCFB.gate(মানুষের তালিকা)` (পপআপ এখানে)।
- admin-dlhub.js — ⬇ ডাউনলোড ট্যাবের নামের তালিকা: টিক ও ৫/৭/১০/প্রথম N বাটন।
- admin-sheet.js — শিট-জানালার নামের তালিকা: টিক, ১–৫/সব/কাস্টম বাটন, ➕ নাম যোগ।
- sw.js — ক্যাশ নাম mc-challenge-205।
