# লোগো ড্রপডাউন (বাম/ডান আলাদা) — ২০২৬-১১-১৬
- ড্রপডাউন "🖼️ লোগো বাছুন": বাম ও ডানের জন্য আলাদা। অপশন: ডিফল্ট (অ্যাডমিনের সেটিং যেমন) / প্রতিটা লোগো / ✍️ অক্ষর লিখব (১-৩ অক্ষর, বেশি হলে ছোট হয়ে বৃত্তে আঁটে)।
- কোথায়: (১) ইউজারের ফল-পাতার স্কোর কার্ড — ১ ২ ৩ ডিজাইন বাটনের ঠিক নিচে (স্টোরিতেও একই বাছাই খাটে); (২) ইউজারের "আগের কার্ড"-এর বড় প্রিভিউ — ছবির নিচে, ডাউনলোডের ওপরে; (৩) অ্যাডমিনের কার্ড-প্রিভিউ (বিজয়ীদের কার্ডসহ) — সবসময় চালু, সব লোগো + অক্ষর।
- ইউজারের জন্য ডিফল্টে সব বন্ধ। অ্যাডমিন > 🖼️ লোগো > ৬) থেকে: ফল-পাতা / আগের কার্ড আলাদা সুইচ, ইউজার কোন কোন লোগো বাছতে পারবে (টিক), ইউজার নিজে অক্ষর লিখতে পারবে কি না।
- বাছাই শুধু ওই একটা কার্ড আঁকার জন্য: সার্ভারে কিছু জমা হয় না, সাইটের সেটিং বা অন্য কার্ড বদলায় না, নতুন SQL লাগে না। সেটিং mc2_settings 'logo_cfg'-এর ভেতরে নতুন তিন চাবি: ud {s,h}, ul [লোগো-নম্বর], ut।
