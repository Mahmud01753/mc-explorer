# ২০২৬-১২-১৬ — ভাগ ৩: 🪪 কার্ড ট্যাবে "📦 ZIP (JPG + এক্সেল + PDF)" — নতুন SQL লাগে না

**SQL/স্টোরেজ:** কোনো নতুন SQL, টেবিল, কলাম বা সার্ভারে জমানো ডাটা নেই। সবকিছু অ্যাডমিনের ব্রাউজারে তৈরি; শুধু বিদ্যমান `mc2_cards` ও `mc2_draw_admin_list` পড়া।

## কী যোগ হলো
- 🪪 কার্ড ট্যাবের বাটন-সারিতে **📦 ZIP** → নির্বাচন-জানালা: **সংখ্যা (১০–১০০; বাইরে লিখলে ১০ বা ১০০-এ আসে)**, বিভাগ, সেশন, **বিজয়ী** (সব কার্ড / শুধু বিজয়ী — যেকোনো ঘোষণা / নির্দিষ্ট একটা ঘোষণা), **সময়** (শেষ আপডেট: আজ, শেষ ৭/৩০ দিন, এই মাস, কাস্টম তারিখ), সাজানো (বেশি স্কোর আগে / নতুন আগে), কার্ডের ডিজাইন (ডিফল্ট / কার্ড ১-৩ / স্টোরি)। "🔎 কয়টি মিলল" বাটনে আগে গুনে দেখা যায়।
- ZIP-এর ভেতরে: `cards/` (কার্ড JPG, ক্রমিক নম্বর + নাম + স্কোর) · `cards.xlsx` (admin-xlsx.js-এর একই ডিজাইন; নাম, বিভাগ, সেশন, স্কোর, শতাংশ, বিজয়ী ঘোষণা, JPG ফাইলের নাম, KB, শেষ আপডেট) · `cards.pdf` (A4; প্রতি পাতায় ৪টি বা ১টি, "No. n / মোট" ক্রমিক) · `README.txt`।
- **JPG ১০০ KB-এর নিচে:** আগে মান কমানো (০.৮৮ → ০.৩), তাতে না হলে মাপ ৮৫% করে ছোট করা (কমপক্ষে ~৫৪০px চওড়া)। তবুও না হলে ফাইলটা থাকে, কিন্তু ZIP-এর নিচে "⚠️ N টি JPG ১০০ KB-এর নিচে নামানো যায়নি" লেখা আসে। ছবি-ভারী কার্ডে মাপ ১০৮০ থেকে কমে আসতে পারে।
- **লাইব্রেরি:** JSZip 3.10.1 ও jsPDF 2.5.1 — cdnjs, নির্দিষ্ট ভার্সন, শুধু "ZIP বানান" চাপলে প্রথমবার লোড হয়; সাধারণ পাতায় নয়।
- PDF-এ শুধু ইংরেজি অক্ষরের ক্রমিক (বাংলা ফন্ট এম্বেড লাগে না); বাংলা লেখা কার্ডের ছবির ভেতরেই। আইপি/ফোন/ডিভাইস কোনো ফাইলে যায় না।
- ডাউনলোড-লিংক তৈরি থাকে, অ্যাডমিন নিজে চাপে (ফোনের ব্রাউজার দেরিতে-চালানো ডাউনলোড আটকায়)। "⏹ থামান" দিলে যতটা হয়েছে ততটার ZIP হয়।

## বদলানো/নতুন ফাইল
`admin-export.js` (নতুন), `admin-cards.js` (বাটন + `window.MCA_CARDX` — কার্ড আঁকার বিদ্যমান ফাংশন শেয়ার, নকল কোড নেই), `admin.html` (script ট্যাগ), `_headers` ও `netlify.toml` (শুধু /admin ও /admin.html-এর CSP `script-src`-এ `https://cdnjs.cloudflare.com` যোগ; অন্য কিছু নয়), `sw.js` (ক্যাশ ১৫৬ → ১৫৭), `status.html`, `files.txt`, `sql-status.md`, এই নোট।

## যাচাই (এই সেশনে) — ও যা দেখা হয়নি
- আসল Chromium-এ আসল `admin-export.js` + `admin-xlsx.js` + আসল JSZip 3.10.1 দিয়ে নকল ডাটায় চালিয়েছি: সংখ্যা ক্ল্যাম্প (৫ → ১০), বিভাগ ফিল্টার, বিজয়ী ফিল্টার (নাম+বিভাগ মেলা; খালি-বিভাগের বিজয়ী নামে মেলে; ম্যানুয়াল কার্ড-ঘোষণা বাদ), ১২টি JPG সবই ১০০ KB-এর নিচে (সহজ কার্ড ~২৫ KB/১০৮০px, ভারী কার্ড ~৯৮ KB/৫৬৪px), `openpyxl`-এ এক্সেলের ব্যানার/হেডার/১২ সারি ঠিক, JS এরর নেই।
- **দেখা হয়নি:** (১) আসল jsPDF — এখানে নেটওয়ার্ক বন্ধ, তাই jsPDF-এর জায়গায় নকল বসিয়ে শুধু আমার ডাকগুলো (A4, addImage-এর মাপ/ক্রম, পাতা-সংখ্যা, "No. n/মোট") যাচাই করেছি; আসল PDF খুলে দেখা হয়নি। (২) আসল cdnjs-এ ফাইল পাওয়া ও CSP — ডিপ্লয়ের পর প্রথম ZIP বানিয়ে দেখুন; না এলে নিচে লাল লেখায় কারণ আসবে। (৩) আসল Supabase ডাটা, আসল কার্ড-আঁকা (বাংলা ফন্ট/ছবি) ও আসল ফোন/Excel অ্যাপ। (৪) SRI hash বসানো নেই (অফলাইনে হিসাব করা যায়নি)। (৫) ১০০টি কার্ড একসাথে ফোনে কত সময়/মেমোরি নেয় — ধীর ফোনে কম সংখ্যা দিয়ে শুরু করুন।
