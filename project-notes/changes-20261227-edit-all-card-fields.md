# ২০২৬-১২-২৭ — ⬇ ডাউনলোড › ✏️ এডিট-প্যানেলে কার্ডের সব ঘর এডিটেবল

## স্কোর কার্ড (নেভি মেডালিয়ন = card1, সবুজ উইনার = card2, গ্লাস রিং = card3, স্টোরি)
- নতুন ভাঁজ "✍️ কার্ডের সব লেখা / ঘর (এই ডিজাইনের)": যে ডিজাইন বাছা, শুধু তার ঘরগুলো আসে। ফাঁকা = ডিফল্ট (ধূসর placeholder-এ ডিফল্ট দেখায়)।
  ঘর: কলেজের নাম (বাংলা/ইংরেজি), ব্র্যান্ড-লেখা, WINNER-প্লেট, শিরোনাম "MC কতটুকু জানো?", ক্লাস ব্যাজ, "জানি", ট্যাগলাইন, মার্ক-পিলের লেখা,
  র‍্যাংক-পদকের ছোট/বড় লেখা, সেরা-জায়গার লেবেল, "উপাধি" ট্যাগ, তিন বক্সের লেবেল (+ গেমের ধরন), "স্ক্যান করে খেলো" লাইন, তারিখ, সেশন-চিপের শব্দ, লোগোর অক্ষর।
- "কার্ডের বাড়তি লেখা" ভাঁজে নতুন: সঠিক উত্তর (সংখ্যা), বিভাগে র‍্যাংক (সংখ্যা)।
- ঠিক করা: এডিটে "র‍্যাংক" বদলালে কার্ডে লাগত না (ডাটাবেজের অটো-র‍্যাংক জিততো) — এখন হাতে বসানো র‍্যাংক/বিভাগ-র‍্যাংক অটোর ওপর বসে (প্রিভিউ + ZIP/JPG দুটোতেই)।
- ডিজাইন বদলালে ঘরের তালিকা নিজে বদলায়।
- কীভাবে: card.js-এ `TXG(o,key,default)` (o.tx); cards.js-এ `applyTx` (rec.tx → o.tx/তারিখ/গেম/ক্লাস/লোগো-অক্ষর/র‍্যাংক-লেবেল); প্রতিজনের বদল `po[..].tx` → ফোনের mc2_dl_edit।
