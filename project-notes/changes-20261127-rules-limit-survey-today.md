# 2026-11-27 — নিয়মের পপ-আপ সীমা, সার্ভে সার্ভারে, হোমের "আজ" সার্ভার থেকে, লিডারবোর্ড-বন্ধের অমিল
**SQL: নতুন লাগে — `supabase-new-20261127.sql` (শুধু সার্ভের জন্য)। বাকি সব SQL ছাড়াই চলে। SQL না চালালে সার্ভে ফোনের লোকাল মোডে চলে, অ্যাডমিন সার্ভে-ট্যাব "SQL চালান" বলে।**
1. **নিয়মের পপ-আপ সীমা:** অ্যাডমিন > 🏠 হোম > "🎯 নিয়মের পপ-আপ — দিনে কতবার" (`home_cfg.rl = {on, max}`; ডিফল্ট চালু, ৩)। শুধু খেলা শুরুর আগের পপ-আপ গোনা হয় (ফোনে `mc2_rl` = {d: তারিখ, n}); "ℹ️ বিস্তারিত" সবসময় খোলে। সীমা বন্ধ = আগের মতো প্রতিবার।
2. **সার্ভে সার্ভারে:** টেবিল `mc2_survey_opts` (অপশন), `mc2_survey_votes` (এক ডিভাইসে একটা ভোট); RPC `mc2_survey_get` / `mc2_survey_submit`; সাইটে `community.js` > `window.mcSurvey`, `app.js` > `survey()`। অ্যাডমিন নতুন ট্যাব "📊 সার্ভে" (`admin-survey.js`): যোগ / নাম বদল / ▲▼ ক্রম / লুকানো / ডিলিট + সবার হিসাব। সার্ভার না পেলে আগের ডিফল্ট তালিকা + ফোনের লোকাল ভোট (সৎ নোটসহ)।
3. **হোমের "আজ N জন খেলেছে / সেরা বিভাগ আজ / আজকের শীর্ষ ৩":** এখন সার্ভার থেকে (`window.mcToday` = বিদ্যমান `mc2_board`-এ from = আজ ভোর; ৬০ সেকেন্ড ক্যাশ)। সার্ভার না পেলে ফোনের আজকের স্কোরে ফল্লব্যাক।
4. **লিডারবোর্ড বন্ধ থাকলে:** হোমের `#hbTop`/`#hbToday` লুকায় (`ui-config.js`); সার্ভের শেষে "লিডারবোর্ডে যাও"-র বদলে "হোমে ফিরো"; কার্ডের ছবির বোতামে সেরা-৩ লেখা বাদ।
5. **লিডারবোর্ডের নোট:** সার্ভার না পেলে "সার্ভার পাওয়া যায়নি — শুধু এই ফোনের ফল" দেখায়।
