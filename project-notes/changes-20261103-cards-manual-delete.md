# 2026-11-03 কার্ডের ম্যানুয়াল ডিলিট (অ্যাডমিন > 🪪 কার্ড > 🗑 কার্ড ডিলিট)
- admin-cards.js: ফিল্টারে নতুন আইডেন্টিফায়ার (পরিচয়, জেন্ডার, ক্লাব, টাইটেল, আইপি, ফোন মডেল, এক ডিভাইসে কার্ড সংখ্যা, একই ব্যক্তির কার্ড সংখ্যা, মোট খেলা, শতকরা, কার্ডের KB, টপ-৩ সুরক্ষিত/কখনো টপে উঠেছে, ফর্ম জমা দিয়েছে কি না) + সাজানো (KB / ডিভাইসে কার্ড)।
- প্রতি কার্ডের KB (প্রিভিউ + ছবি আলাদা), বাছা কার্ডের মোট KB, ফিল্টারের মোট KB, সব কার্ডের মোট MB ও গড় KB; মুছতে গেলে "≈ কত জায়গা খালি হবে" কনফার্মে দেখায়।
- তালিকার কার্ড-ছবিতে ক্লিক করলে এক-কার্ড প্রিভিউ: কার্ড ১ / ২ / ৩ / স্টোরি ট্যাব, ৪টারই আলাদা ডাউনলোড (সার্ভারে বাড়তি জায়গা ০ KB — ফোনেই আঁকা হয়)।
- টপ-৩ সুরক্ষিত কার্ড ডিফল্টে ফিল্টার থেকে বাদ ("বাদ দিয়ে"); মুছতে চাইলে "সব সহ"। সব-মোছা এখন আইডি ধরে ধরে মোছে।
