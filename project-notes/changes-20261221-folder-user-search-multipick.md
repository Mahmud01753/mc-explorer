# 2026-12-21 (ভাগ ২/৩) — 📁 ফোল্ডারে "🔎 ইউজার খুঁজে যোগ করুন" + একাধিক-বাছার ফিল্টার (নতুন SQL নেই, sw.js mc-challenge-207)

## কোথায়
অ্যাডমিন > 📁 ফোল্ডার (admin-prize.js-এর ভেতরে খোলে) > নিচের "কোন ফোল্ডারে" প্যানেল: হাতে-নাম-লেখার ঘরের নিচে নতুন বাটন **🔎 ইউজার খুঁজে যোগ করুন**। (হাতে-নাম-লেখা, 📋 কপি, ✂️ মুভ আগের মতোই আছে।)

## ১) সার্চ প্যানেল
- ফিল্টার: ধরন (ছাত্র/ছাত্রী/স্যার/ম্যাম/ভিজিটর) · বিভাগ · সেশন · ক্লাব (চারটাতেই একাধিক টিক) · তারিখ (সব সময়/আজ/গতকাল/এই সপ্তাহ/এই মাস/কাস্টম) · নাম।
- ডাটা-উৎস: ভিউ mc2_cards_adm (supabase-new-20261103.sql, আগেই চালানো)। শুধু পড়া — সার্ভারে কিছু জমে না। ভিউ না থাকলে mc2_cards-এ ফিরে যায়: ধরন/ক্লাব বাদ, বাকিগুলো চলে (লাল নোটিস দেখায়)।
- সার্ভারেই ফিল্টার হয়, ৩০টা করে আসে, "⬇ আরও দেখান" বাটন; মোট কত কার্ড তাও দেখায়। হাজার হাজার কার্ডেও ধীর হয় না।
- তারিখ = কার্ডের শেষ আপডেট (updated_at)। একই ব্যক্তির একাধিক কার্ড থাকলে তালিকায় একজনই দেখায়।
- বাছা: প্রতিটার টিক · "☑ দেখানো সবাই" · "☑ ফিল্টারের সব" (সর্বোচ্চ ৫০০০ জন, ১০০০ করে আনে) · "✕ বাছা মুছুন"।
- "➕ বাছা N জনকে যোগ করুন": ওপরের "কোন ফোল্ডারে" ঘরের ফোল্ডারে (বা ➕ নতুন ফোল্ডার) যোগ হয়; আগে থাকা জন বাদ পড়ে ও সংখ্যা বলে। স্মার্ট ফোল্ডারে যোগ করা যায় না (আগের নিয়ম)।
- নতুন যোগ-হওয়া সারি আগের মতোই mc2_ufolder_members-এ যায় (ukey = ডিভাইস+নাম, src = all)।

## ৫) মূল তালিকার ফিল্টারে একাধিক-বাছা
বিভাগ · সেশন · অবস্থা এখন টিক-বাক্সের ড্রপডাউন ("↺ সব বাদ" বাটনসহ)। আগে সেভ-করা স্মার্ট ফোল্ডারের একক মান (যেমন dept:"CHE") হুবহু আগের মতো কাজ করে। ধরন/ক্লাব মূল তালিকায় নেই: ফোল্ডার-সদস্যের টেবিলে ওই দুটো কলাম নেই (যোগ করতে SQL লাগত) — সার্চ প্যানেলে আছে।
