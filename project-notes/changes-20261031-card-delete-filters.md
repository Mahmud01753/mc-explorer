# 2026-10-31 — কার্ড ট্যাব: ফিল্টার দিয়ে একসাথে ডিলিট
- ফাইল: admin-cards.js (নতুন SQL লাগে না)
- "🗑 কার্ড ডিলিট (ফিল্টার দিয়ে)" বাটনে ক্লিক করলে নিচে প্যানেল খোলে।
- ফিল্টার: নাম, বিভাগ, সেশন (আসল ডেটা থেকে তালিকা), স্কোর থেকে/পর্যন্ত, সঠিক উত্তর থেকে/পর্যন্ত, কত দিনের পুরোনো (প্রিসেট + কাস্টম দিন), শেষ কত দিনের মধ্যের, কাস্টম তারিখ-সময় থেকে/পর্যন্ত, আপডেট/তৈরির সময় বেছে নেওয়া, র‍্যাংক থেকে/পর্যন্ত, টপ-৩ ছবি দেখানো/লুকানো, কার্ডে ছবি আছে/নেই, ডিভাইস আইডি, সাজানো।
- ফলাফল: মোট সংখ্যা + পেজ-ভাগ (৫০টি করে) + সিরিয়াল; হাতে টিক বা "ফিল্টারের সব" বেছে ডিলিট। ২০টির বেশি হলে সংখ্যা লিখে নিশ্চিত করতে হয়।
