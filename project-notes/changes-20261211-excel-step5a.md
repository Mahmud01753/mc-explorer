# ২০২৬-১২-১১ — ধাপ ৫-ক: ছয়টা ট্যাবে "⬇ এক্সেল (সাজানো)" বাটন — নতুন SQL লাগে না

**SQL:** কোনো নতুন SQL নেই। কোনো টেবিল/কলাম/ডাটা বাড়েনি, স্টোরেজে কিছু জমে না; শুধু আগে থেকে থাকা ডাটা পড়ে। `_headers`/CSP অপরিবর্তিত (বাইরের লাইব্রেরি নেই)।

## কোন কোন ট্যাবে এখন বাটন আছে (৫-ক)
১. 📊 সার্ভে (`mc2_survey_opts` + `mc2_survey_get`) · ২. 🏆 লিডারবোর্ড সেটিংস (`mc2_board_admin_list`) · ৩. 🏆 স্কোর (`mc2_scores`) · ৪. 👥 ভিজিটর (`mc2_visits`) · ৫. 👤 User Info (`mc2_admin_users2`) · ৬. 🎁 পুরস্কার ও নোট (`mc2_draw_admin_list` + `mc2_pn_list`)।
(📊 ফলাফল আগে থেকেই ছিল।) **বাকি আছে:** ৫-খ (🪪 কার্ড, 🏅 বিজয়ী ঘোষণা, 🏆 বিজয়ী কার্ড সেটিংস, 🖼 কুইজ ছবি/কুইজ, ফোল্ডার/স্মার্ট ফোল্ডার, গ্যালারি), ৫-গ (💬 চ্যাট, 💬 বেনামি চ্যাট, 🛡 মডারেশন, 🗑 বিন), ৫-ঘ (🖼 কার্ড প্রিভিউ)।

## কী হলো
- প্রতি ট্যাবের ওপরে ডানদিকে "⬇ এক্সেল (সাজানো)" বাটন নিজে বসে। চাপলে আগে ডাটা আসে, তারপর ধাপ ৪-এর একই ফিল্টার-জানালা ও কলাম-নির্বাচক খোলে; "⬇ নামান" চাপলে ফাইল।
- ফাইলের ডিজাইন একই (ব্যানার, ৪ বক্স, ৩ লাইনের সারসংক্ষেপ, সাজানো টেবিল, ফ্রিজ, ফিল্টার, জেব্রা, ফুটার)। প্রতি ট্যাবের কলাম, বক্স ও "এক নজরে" লাইন আলাদা। র‍্যাংক/স্কোর থাকলে (স্কোর, লিডারবোর্ড) স্কোর-ঘর ক্লাসের রঙে, ১ম–৩য় বক্সসহ; যেখানে র‍্যাংক নেই (ভিজিটর, পুরস্কার ও নোট ইত্যাদি) সেখানে সারসংক্ষেপ-বক্স।
- ফিল্টার ডাটা অনুযায়ী: সময় (যেখানে তারিখ আছে), নাম খুঁজুন, বিভাগ/সেশন, স্কোর/শতাংশ/সঠিক, তালিকার ধরন, সাজানো। যে ফিল্টারের কলাম ডাটায় নেই তা দেখায় না।
- সব সংখ্যা-কলাম আসল সংখ্যা (সর্ট/যোগ চলে); ক্রমিক/র‍্যাংক বাংলা অঙ্কের লেখা; নামের শুরুতে "=" থাকলেও ফর্মুলা হয় না (লেখা সবসময় টেক্সট)।
- ব্যক্তিগত তথ্য আগের চেয়ে বাড়েনি: ভিজিটর-ফাইলে আগের CSV-র মতোই সময়, ডিভাইস, আইপি, পেজ, ইউজার-এজেন্ট ও তথ্য; User Info-তে ফোন নম্বর যায় না; স্কোর-ফাইলে ডিভাইস/আইপি নেই।
- পুরোনো CSV বাটন ও 📊 ফলাফলের এক্সেল আগের মতোই (পুরোনো ফাইল বদলে ফেলা ডাকেও ফল একই)।

## বদলানো/নতুন ফাইল
`admin-xtab.js` (নতুন; ছয় ট্যাবের কনফিগ + বাটন বসানো; ৫-খ/৫-গ-র ট্যাব `MCXTAB.add(চাবি, cfg)` দিয়ে এখানেই যোগ হবে), `admin-xlsx.js` (`results()` এখন ঐচ্ছিক `colDefs/colOrder/sheet/sub/boxes/pod…` নেয়; না দিলে আগের মতোই), `admin.html` (script ট্যাগ), `sw.js` (ক্যাশ ১৪৭ → ১৪৮), `status.html`, `files.txt`, `sql-status.md`, এই নোট। অন্য ট্যাবের ফাইল ছোঁয়া হয়নি।

## যাচাই (এই সেশনে) — ও যা দেখা হয়নি
- নকল ডাটা দিয়ে Chromium-এ (ফোন-মাপ ৩৯০px) আসল `admin-xlsx.js` + `admin-xdlg.js` + `admin-xtab.js` চালিয়েছি: সার্ভে/স্কোর/পুরস্কার-ও-নোট ট্যাবে বাটন বসে, জানালা খোলে, লাইভ সারি-সংখ্যা আসে, ফাইল নামে, JS এরর নেই। আলাদাভাবে ছয়টা ট্যাবের ফাইলই নামিয়ে `openpyxl`-এ ব্যানার/বক্স/এক নজরে/হেডার/ফ্রিজ/ফিল্টার মিলিয়েছি; পুরোনো `results()` ডাকও ঠিক আছে।
- **দেখা হয়নি:** আসল Supabase ডাটা ও আসল অ্যাডমিন লগইন; আসল RPC-র ফিল্ড-নাম কোড পড়ে ধরেছি (যেমন লিডারবোর্ডে `sc/ok/total/hidden/has_card`, User Info-তে `gname/gdept/best/ls`), তাই কোনো কলাম ফাঁকা এলে জানাও; ভিজিটর ও User Info ট্যাবের বাটন বসা আলাদা করে ব্রাউজারে দেখিনি (একই কোড); মালিকের ফোন/Excel অ্যাপ।
- লিডারবোর্ড ট্যাবের র‍্যাংক = ওই তালিকার স্কোর অনুযায়ী (সমান স্কোরে একই), সার্ভারের হিসাব নয়।
