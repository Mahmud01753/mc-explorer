- admin-cards.js: ডিফল্ট ভিউ এখন এক লাইনের লেখা-সারি (ছবি নেই): টিক · ক্রম · নাম · বিভাগ · সেশন · মার্ক · তারিখ · 🗑। সারিতে ক্লিকে ছোট প্রিভিউ + ডাউনলোড খোলে/বন্ধ হয়। ওপরে "📋 লেখা ভিউ / 🖼 ছবি ভিউ" টগল (ব্রাউজারে মনে থাকে); ছবি ভিউতেও টিক আছে।
