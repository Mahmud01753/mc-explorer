# 2026-12-21 — ⬇ ডাউনলোড ট্যাবে লাল "✏️ এডিট" বাটন (নতুন SQL নেই, সার্ভারে কিছু জমে না, sw.js mc-challenge-204)

## কী বানানো হয়েছে
- ⬇ ডাউনলোড ট্যাব → 🗂 কার্ডের ধরন (🪪 ফলাফল / 🎓 সনদ / 📣 সোশ্যাল / 🏅 র‍্যাংক / 📱 স্টোরি) বেছে → ফোল্ডার-ড্রপডাউন বাছলে তার ওপরে লাল **"✏️ এডিট"** বাটন আসে। তালিকায় নামের পাশে ✅ টিক দিলে বাটন চালু হয়।
- বাটনে চাপলে `admin-sheet.js`-এর এডিট-প্যানেল নতুন "ডাউনলোড-এডিট মোডে" খোলে (`MCSheet.open(people, { dl: { edit:true, folder, ct, kind, fname, cname, start } })`):
  - ওপরে নামের ড্রপডাউন (শুধু ✅ করা জনেরা) + ১ ২ ৩… সংখ্যা (যত জন ✅ তত) + "পরের ▶"। শেষে-টিক-করা জনের কার্ড দিয়ে জানালা খোলে।
  - "💾 সেভ" = এখন যার কার্ডে আছি তার এডিট + ডিজাইন সেভ, জানালা খোলা থাকে। "সেভ ও বন্ধ" = সবার এডিট সেভ + বন্ধ। ✕ = বন্ধ; সেভ-না-করা বদল থাকলে আগে confirm।
  - এডিটের সময় বদল শুধু মেমরিতে (draft); "● সেভ হয়নি" দেখায়।
- সেভ হয় শুধু ফোনে (localStorage) নতুন চাবি **`mc2_dl_edit`**-এ (`admin-dledit.js`, `window.MCDLE`)।

## ৭ নম্বর নিয়ম (ডিজাইন বনাম প্রতিজন)
- 🎨 **ডিজাইন / টেমপ্লেট / রং** (কার্ড ১-২-৩, পোস্টার-থিম, সনদ-সোশ্যালের রং ও লেখা) = `f[ফোল্ডার].t[ধরন-আইডি]`: ফোল্ডারের ওই ধরনের সব ✅-কার্ডে লাগে (`who` = সেভের সময়কার ✅ তালিকা, আগেরগুলোর সাথে যুক্ত হয়)।
- ✏️ **প্রতিজনের লেখা** (নাম, বিভাগ, সেশন, মার্ক, র‍্যাংক, শতকরা…, ছবি) = `f[ফোল্ডার].p[ব্যক্তির চাবি]`: শুধু ওই একজনের কার্ডে।

## কোথায় লাগে
- ফোল্ডার-ডাউনলোড (`MCEXP.folder`, `admin-export.js` `fgo`): ⬇ ট্যাব থেকে খুললে `id` যায়; JPG/ZIP-এর কার্ড আঁকার সময় প্রতিজনের বদল + ডিজাইন (শুধু ✅-তালিকার জনেরা, ধরন `res`) লাগে। "কার্ডের ডিজাইন" বাছাই "ডিফল্ট" থাকলে সেভ-করা ডিজাইন চলে; নিজে অন্য ডিজাইন বাছলে সেটাই চলে। এক্সেলে এডিট লাগে না।
- ⬇ ট্যাবের কার্ডের তালিকায় ফোল্ডার বাছা থাকলে "📄 গ্রুপ পেজ / 🖼 একা কার্ড" শিটও `mc2_dl_edit` পড়ে-লেখে (mc2_sheet_po/ov নয়)।

## যা বদলায়নি (শর্ত)
- মূল সাইট, লিডারবোর্ড, অন্য অ্যাডমিন ট্যাব (🪪 কার্ড, 📣 সোশ্যাল, 🏆 বিজয়ী, 📁 ফোল্ডার…), এবং ⬇ ট্যাব ছাড়া বাকি জায়গায় বসানো তালিকা (`MCDL.mount`): আগের মতোই `mc2_sheet_po`, `mc2_sheet_ov`, `mc2_sheet_cfg` — একটা বাইটও বদলায় না। এডিট-মোডে `mc2_sheet_cfg`-ও লেখা হয় না।
- 📁 ফোল্ডার ট্যাবের নিজের "⬇ ডাউনলোড" বাটনে `id` পাঠানো হয়নি, তাই সেখানে ডাউনলোড-এডিট লাগে না।
