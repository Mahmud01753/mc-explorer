# ২০২৬-১২-০৩ — বিজয়ী কার্ড বাছাইয়ে ✏️ সম্পাদনা — ⚠️ supabase-new-20261203.sql লাগবে (একবার Run)

কী হলো:
- অ্যাডমিন > বিজয়ী ঘোষণা > "🖼 সব কার্ড দেখে একসাথে বাছুন" জানালায় (৩ স্কোর কার্ড + ২০ বিজয়ী ডিজাইন) প্রতিটা বিজয়ী-ডিজাইন কার্ডের নিচে এখন "✏️ সম্পাদনা" বাটন।
- চাপলে ওই ডিজাইন নিয়ে পোস্টার-এডিটর খোলে (বিজয়ীর নাম/বিভাগ/সেশন/র‍্যাংক/মার্ক/ছবি অন-অফ, ডিজাইন বদল, ব্যাজ/বার্তা/স্লোগান/নিচের শেপ/শিরোনাম, লিংক-পিলের রঙ, QR, লেখার সাইজ-অ্যালাইনমেন্ট)। ডাউনলোড (JPG/PNG) আগের মতোই।
- নতুন "💾 এই সম্পাদিত কার্ড সেভ করুন" বাটন: সম্পাদিত কার্ড ওই বিজয়ীর তালিকায় নতুন কার্ড হয়ে বসে ("✏️ সম্পাদিত — ডিজাইন নাম"), টিক দেওয়া অবস্থায়। পরে আবার ✏️ চেপে একই কার্ড বদলে সেভ করলে পুরোনোটার জায়গায় বসে। স্থায়ী করতে জানালার "✅ সব বিজয়ীর বাছাই রাখুন" চাপতে হয় (ঘোষণা-তালিকা থেকে খুললে এতেই ডাটাবেজে সেভ হয়)।
- পাবলিক বিজয়ী তালিকায় "🪪 কার্ড দেখুন" চাপলে সম্পাদিত কার্ডও ট্যাবে আসে ("✏️ ডিজাইন N") ও ডাউনলোড হয়।

ডাটা: `cs.l`-এ নতুন কোড `e<ডিজাইন ০-১৯>.<base64url(JSON)>` (JSON = { s: ডিজাইন-সেটিংয়ের বদল, v: বিজয়ীর তথ্যের বদল }), সর্বোচ্চ ১৬০০ অক্ষর। ছবি জমা হয় না; কার্ড ফোনে আবার আঁকা হয়। কাস্টম লোগো (বাম/ডান) সম্পাদিত কার্ডে সেভ হয় না (সবসময় সাইটের ডিফল্ট লোগো)।
