# ২০২৬-১২-০৪ — 🖼 পোস্টার জানালায় কার্ড সেভ + ডিজাইন নং ও সেভ-কার্ড সংখ্যা ভেতরেই
- admin-winners.js (MCW_DESIGN) + admin-prize.js: বিজয়ীর পাশের "🖼 পোস্টার ✔N" জানালার ভেতরে এখন "💾 এই সম্পাদিত কার্ড সেভ করুন (সরাসরি ডাটাবেজে)" ও "🔎 ডাটাবেজে আছে কি না নিশ্চিত করুন" বাটন আছে। সেভ = ডাটাবেজে লেখা + সার্ভার থেকে আবার পড়ে মিলিয়ে তবেই "সেভ হয়েছে"; এক ডিজাইনের একটাই সম্পাদিত কপি, শেষটাই থাকে।
- জানালার ভেতরের লেখায় এখন "🎴 সেভ-করা কার্ড: N টি (সম্পাদিত M টি)" ও "সেভ করা ডিজাইন নং N — নাম" (আগে শুধু নাম ছিল)।
- মোড কাস্টম থাকলে ও ডিজাইন নম্বর সেভ থাকলে জানালায় সতর্কবার্তা: পাবলিকে নম্বর-ডিজাইন কার্ড বদলায় না, শুধু বাছা কার্ড দেখায়।
