# ধাপ ২ — "সেভ হয়নি" সতর্কতা + ট্যাবের ব্যাখ্যা + ✅ সব ঠিক আছে? বক্স

বদলেছে (শুধু ২টা): `admin-hub.js`, `sw.js` (mc-challenge-145)। নতুন SQL লাগে না। নতুন ফাইল নেই।

১. "সেভ হয়নি" সতর্কতা — নতুন কোড লাগেনি: এটা আগে থেকেই `admin-keep.js`-এ আছে (বদল করে ট্যাব বদলাতে গেলে "⚠️ সেভ-না-করা বদল আছে" ডায়ালগ + "থাকুন / বদল ফেলে যান"; পেজ ছাড়তে/রিলোডে ব্রাউজারের নিজস্ব সতর্কতা; সেভ চাপলে আর আসে না)। `admin-keep.js` অপরিবর্তিত।
২. ট্যাবের এক-লাইন ব্যাখ্যা (`#mcBar`-এ, ধূসর ছোট লেখা) আগে ২৪টা ট্যাবে ছিল; যোগ হয়েছে বাকি ৩টায়: 🏆 বিজয়ী কার্ড সেটিংস (wcs), 📊 সার্ভে (survey), 🖼 কুইজ ছবি (qimg)। ফলে এই তিন ট্যাবের বাঁ পাশে গ্রুপের রঙের দাগ আর `?` সাহায্যও এল (অন্য ট্যাবের মতো)।
৩. 🧭 শুরু করুন ট্যাবের ওপরে "✅ সব ঠিক আছে?" বক্স (শুধু পড়ে, কিছু লেখে না):
   - 🗄 SQL: `sql-status.md` ওপর থেকে নিচে পড়ে; "# ⚠️"/"# ⏳" লাইন (✅ ছাড়া) = লাল ⚠️ "SQL বাকি"; প্রথম "# ✅" লাইনে থামে। কিছু বাকি না থাকলে সবুজ ✔। ফাইল পড়া না গেলে নিজে কিছু দাবি করে না।
   - ⚙️ সেটিং: `mc2_settings`-এ key না থাকলে লাল ⚠️ "ফাঁকা (সাইট ডিফল্টে চলছে)"; দেখা key: quiz_count, ui_cfg, home_cfg, board_cfg, card_cfg, logo_cfg, qimg_cfg। সব থাকলে সবুজ ✔।
   - নিয়ম মনে রেখো: নতুন SQL এলে `sql-status.md`-র একদম ওপরে "# ⚠️ … চালানো হয়নি" লাইন লিখলে বক্স নিজে দেখাবে; মালিক "চালানো হয়েছে" বললে ওই লাইন "# ✅ …" করলে বক্স থেকে সরবে।
