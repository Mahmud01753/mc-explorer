# ভাসমান 🔎 সার্চ বাটন — সব জায়গায় (ভাগ ৪)
- নতুন float-search.js: নিচে-ডানে বড় (≥৫৬px) উজ্জ্বল গ্রেডিয়েন্ট + ছায়ার "🔎 সার্চ" বাটন (position:fixed)। scroll-btn.js-এর ⬆⬇ বাটনের ঠিক ওপরে বসে, তাই ওভারল্যাপ করে না।
- লিডারবোর্ড (#board): ফিল্টার খোলা থাকলে (#lfs দৃশ্যমান) বাটন আসে, চাপলে #lfs.click()। মূল বাটন যেমন ছিল তেমনই।
- অ্যাডমিন: সব ট্যাবে একটাই জেনেরিক বাটন। বর্তমান ভিউর (#view) প্রথম দৃশ্যমান সার্চ বাটন (data-a="go"/"bfgo"/"cd_go"/"sqs"/"qs", id fgo/unS/bdGo, "প্রয়োগ", বা লেখায় 🔎/খুঁজুন/সার্চ/ফিল্টার করুন) খুঁজে .click() করে। বন্ধ/মুছুন/চিপ-ধরনের বাটন বাদ। ট্যাব বা ভিউ বদলালে (MutationObserver) নিজে আপডেট হয়; সার্চ বাটন না থাকলে লুকায়। কোনো ট্যাব-ফাইল আলাদা করে বদলাইনি।
- index.html: দেরিতে-লোড তালিকায় float-search.js যোগ (scroll-btn.js-এর পরে)। admin.html: script যোগ।
- sw.js: ক্যাশ-তালিকা বলে আলাদা কিছু নেই (রানটাইমে ক্যাশ করে), তাই শুধু K = mc-challenge-64।
- বিনে "🗑 ফিল্টারের N টি চিরতরে মুছুন" বাটন ফেরানো হয়েছে (ভাগ ৩-এর সংশোধন): প্রগ্রেস ও কনফার্মসহ চলে।
- SQL লাগে না।
