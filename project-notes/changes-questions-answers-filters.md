# অ্যাডমিন: ❓ প্রশ্ন ও 📝 প্রশ্নভিত্তিক উত্তর ট্যাবে সার্চ ফিল্টার

শুধু একটা ফাইল বদলেছে: `admin-gallery.js`। নতুন SQL লাগবে না। `sw.js`-এর K বাড়ানোর দরকার নেই (অ্যাডমিন ফাইল আগে নেটওয়ার্ক থেকে আসে)।

## ❓ প্রশ্ন
- 🔎 নাম/অপশন খোঁজা (আগে থেকেই ছিল)
- ক্যাটাগরি ফিল্টার: সব / ক্যাটাগরিহীন / প্রতিটি ক্যাটাগরি
- "দেখাচ্ছে X টি (মোট Y টির মধ্যে)" গোনা, "✖ ফিল্টার মুছুন" বাটন
- রিনেম/সেভের পর তালিকা আবার লোড হলেও ফিল্টার থাকে

## 📝 প্রশ্নভিত্তিক উত্তর
- 🔎 খেলোয়াড়ের নাম (আগে থেকেই ছিল)
- 🖼️ ছবির নাম দিয়ে খোঁজা
- ফলাফল: সব খেলা / ভুল উত্তর আছে / সব উত্তর সঠিক / স্কিপ-সময় শেষ আছে
- তারিখ: সব সময় / আজ / গতকাল / এই সপ্তাহ (শনিবার থেকে) / এই মাস / কাস্টম তারিখ (থেকে–পর্যন্ত)
- "ফিল্টারে মোট X টি খেলা", কিছু না মিললে আলাদা বার্তা, "✖ ফিল্টার মুছুন"
- খেলা মোছার পর তালিকা আবার লোড হলেও ফিল্টার থাকে
- ⬇️ CSV আগের মতোই (লোড হওয়া সব উত্তর)
