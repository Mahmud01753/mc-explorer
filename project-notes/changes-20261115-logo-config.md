# কার্ডের লোগো: অন/অফ, কাস্টম অক্ষর, আপলোড-তালিকা, পুরোনো কার্ডের বাছাই
- নতুন `logo-config.js` (সাইট ও অ্যাডমিন দুই জায়গায়): mc2_settings-এর 'logo_cfg' পড়ে (প্রথম কার্ড আঁকার সময় একবার; ইউজারের ফোনে ৫ মিনিট sessionStorage; না এলে ডিফল্ট দুই লোগো)।
- `card.js`: `window.mcLogoPair` — ৪টা ডিজাইনেই (কার্ড ১/২/৩ + স্টোরি; বিজয়ী কার্ড একই ডিজাইন) লোগো অফ হলে বাম/ডানে অক্ষর (ডিফল্ট M / C, কাস্টম, ১-৩ অক্ষর, বেশি হলে ছোট হয়ে বৃত্তে আঁটে)।
- নতুন `admin-logos.js` + admin.html + admin-hub.js: অ্যাডমিন > 🖼️ লোগো — (১) কার্ডভেদে অন/অফ (২) অক্ষরের বক্স (৩) বাম/ডানের লোগো বাছাই (৪) তালিকা + আপলোড (≤৯০ KB PNG, ২৫৬ px, সর্বোচ্চ ১০টি) + মোছা (কয়টা কার্ড ব্যবহার করে দেখায়) (৫) পুরোনো কার্ড নামবে: জমা দেওয়ার সময়ের লোগো (ডিফল্ট) / এখনকার বাছাই / নির্দিষ্ট জোড়া।
- `app.js`, `cards.js`: কার্ড আঁকায় বাছাই করা লোগো/অক্ষর; জমা কার্ডের rec-এ শুধু `lg:[বাম-নম্বর, ডান-নম্বর, মাস্ক, বাম-অক্ষর, ডান-অক্ষর]` (প্রায় ২৫ বাইট; কোনো ছবি জমা হয় না)।
- সার্ভার: নতুন SQL লাগে না। mc2_card_save আগে থেকেই rec-এর বাড়তি চাবি রাখে (সীমা ৪০০০ বাইট)। আপলোড লোগো mc2_settings-এর 'logo_img_<নম্বর>' সারিতে।
- `index.html` (deferred তালিকায় logo-config.js), sw.js ক্যাশ mc-challenge-70।
