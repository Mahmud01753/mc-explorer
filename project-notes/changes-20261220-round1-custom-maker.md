# 2026-12-20 (১২) — প্রথম দফা: কাস্টম সংখ্যা + কার্ড-পপআপে সব ধরনের কার্ড

১) **কাস্টম সংখ্যা:** শিট-জানালায় ৫/৭/১০-এর পাশে "কাস্টম" ঘর + "প্রথম N" (Enter-ও চলে); ⬇ ডাউনলোডের নাম-তালিকার পাতায়ও একই। সর্বোচ্চ ২৪।
৩) **🪪 কার্ড-পপআপে "🛠 বানান ও ডাউনলোড":** 🪪 কার্ড · 📱 স্টোরি · 🖼 বিজয়ী পোস্টার · 🎓 সার্টিফিকেট · 📣 সোশ্যাল কার্ড · 🏅 র‍্যাংক কার্ড · 📋 টাইল — চাপলে ওই একজনের জানালা খোলে (এডিট, ছবি সহ/ছাড়া, ডাউনলোড)।
- নতুন ধরন 🏅 র‍্যাংক কার্ড (সোশ্যাল কার্ডের র‍্যাংক-ধরন; ছবি সহ), 📱 স্টোরি কার্ড (কার্ড ৯:১৬)। সোশ্যাল কার্ডেও এখন ছবি আসে (সহ/ছাড়া/নতুন ছবি, প্রতিজনের বাছাই)।
- ⬇ ডাউনলোড-ফোল্ডারে নতুন: 🏅 র‍্যাংক কার্ড, 📱 স্টোরি কার্ড। গ্রুপ-কার্ড (পডিয়াম, বোর্ড, পরিসংখ্যান, মেসেজ, লাকি ড্র তালিকা) অনেকজনের একটাই কার্ড, তাই সেগুলো 📣 সোশ্যাল ট্যাবে; ⬇ ডাউনলোডে ওই ট্যাবের শর্টকাট বাটন।
